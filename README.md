# quant-journey

My 12-week python journey toward quantitative finance.

本仓库记录我从 python 基础语法，到独立完成第一个因子回测的 12 周过程。
每周的知识点对应一个 .py 文件，全部亲手敲过，不复制粘贴。

## 文件说明

- `01_def_practice.py` — 第 1 周：把星座判断封装成函数（def、return、身份证日期切片）
- `02_file_io.py` — 第 2 周：从 txt 批量读取身份证号，批量输出星座到文件（计划中）

## 如何运行

需要 Python 3。在仓库根目录下执行：

```bash
python 01_def_practice.py
```

## 学习进度

- [x] **第 1 周**：def 函数、return 返回值、身份证日期切片
- [ ] **第 2 周**：文件读写（file I/O）

## 目录约定

所有练习文件直接放在仓库根目录，命名格式为 `NN_主题_practice.py`，`NN` 为周次序号。
